# FM Remake — Downloads

Central de downloads das versões de teste do FM Remake para **Windows 10/11 x64**.

## Baixar o jogo

- [Instalador Windows](https://github.com/Antonio-bevilaqua/fm-remake-downloads/releases/download/v0.1.0-test.20261022.6/FM-Remake-0.1.0-test.20261022.6-Windows-x64-Setup.exe)
- [Versão portátil](https://github.com/Antonio-bevilaqua/fm-remake-downloads/releases/download/v0.1.0-test.20261022.6/FM-Remake-0.1.0-test.20261022.6-Windows-x64-Portatil.zip)
- [Todas as versões e notas](https://github.com/Antonio-bevilaqua/fm-remake-downloads/releases)

O instalador inclui as dependências do aplicativo. Na versão portátil, extraia a pasta inteira antes de abrir **FM Remake Test.exe**. O jogo funciona offline.

## Atualizações

[Patch mais recente: 20261023.5](https://github.com/Antonio-bevilaqua/fm-remake-downloads/releases/tag/v0.1.0-test.20261023.5). Quem já instalou atualiza pelo menu **Atualizações** do jogo, sem reinstalar.

O instalador completo acima permanece na versão 20261022.6. Após instalar, atualize pelo próprio jogo. As novas releases contêm somente patches; o pequeno assistente Setup das releases de patch é para compatibilidade com o atualizador antigo.

## Saves

Os saves ficam em `%APPDATA%\FM-Remake-Test\IndexedDB`. As versões instalada e portátil compartilham esses dados. A desinstalação preserva os saves. Os saves do navegador e da demo são separados.

F11 alterna tela cheia. Os executáveis de teste não têm assinatura digital e podem mostrar um aviso do Windows.

As releases de patch incluem o pacote incremental assinado, instruções e hashes SHA-256. O instalador completo e o portátil permanecem nos links acima.

Esta versão inclui atualizações incrementais assinadas e duelos em rede local. Quem já possui a versão 20261022.1 pode atualizar pelo menu Atualizações. Versões anteriores exigem instalação manual uma vez. Na LAN, ambos precisam da mesma versão; o anfitrião configura os LP e inicia a partida.
